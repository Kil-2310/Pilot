# App: authentication

## Назначение
Приложение предназначено для аутентификация и выхода из аккаунта пилотов. Право на добавление наовых пользователей есть только у администратора системы.
У приложения нет таблиц в БД.

## URL
| URL | View | Метод | Описание | путь к HTML-шаблону
'/login/' | LoginView | POST | Аутентификация | authentication/login.html
'/logout/' | logout_view | POST | Выход из аккаунта | -
